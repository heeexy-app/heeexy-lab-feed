# HEEEXY Lab feed

Every day this workflow looks for strong, **free and openly licensed** AI projects and adds them to
[HEEEXY Lab](https://heeexy.app/lab):

- MCP servers, agent skills and Claude Code add-ons
- AI agents, LLM apps, RAG, local AI, image and voice tools
- n8n and workflow automation projects
- prompt collections and learning resources
- trending open models on Hugging Face

Only projects with a permissive license (MIT, Apache-2.0, BSD, ISC, MPL-2.0, CC0, CC-BY-4.0),
recent activity and real community traction are listed. Each Lab page links back to the original
project and credits its authors.

`python feed.py --dry-run` prints what would be sent.
